## Kết quả chạy
```
=== Bài 3.1: Tính S(n) = 1 + 2 + 3 + ... + n ===
S(5) = 1 + 2 + ... + 5 = 15
S(10) = 1 + 2 + ... + 10 = 55
=== Bài 3.2: Tính S(n) = 1 + 2^2 + 3^2 + ... + n^2 ===
S(3) = 1 + 2^2 + ... + 3^2 = 14
S(10) = 1 + 2^2 + ... + 10^2 = 385
=== Bài 3.3: Tính S(n) = 1 + 1/2 + 1/3 + ... + 1/n ===
S(4) = 1 + 1/2 + ... + 1/4 = 2.0833
S(10) = 1 + 1/2 + ... + 1/10 = 2.9290
=== Bài 3.4: Tính S(x, n) = x^n ===
S(2, 10) = 2^10 = 1024
S(5, 0) = 5^0 = 1
S(2, -3) = 2^-3 = 0.125
=== Bài 3.5: Tìm ước lẻ lớn nhất của n ===
Ước lẻ lớn nhất của 100 là 25
Ước lẻ lớn nhất của 48 là 3
Ước lẻ lớn nhất của 7 là 7
=== Bài 3.6: Tìm ước chung lớn nhất của a, b ===
UCLN(48, 18) = 6
UCLN(17, 5) = 1
=== Bài 3.7: Đếm số chữ số của n ===
Số 7 có 1 chữ số
Số 12345 có 5 chữ số
=== Bài 3.8: Tính S(n) = sqrt(1 + sqrt(2 + ... + sqrt(n))) ===
S(3) = sqrt(1 + sqrt(2 + ... + sqrt(3))) = 1.712265
S(5) = sqrt(1 + sqrt(2 + ... + sqrt(5))) = 1.756238
S(10) = sqrt(1 + sqrt(2 + ... + sqrt(10))) = 1.757933
```
